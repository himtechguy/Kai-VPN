# KAI VPN

A mobile-friendly black-and-white website interface for the KAI VPN project.

## Files
- `index.html` — page structure
- `style.css` — responsive styling
- `script.js` — interface interactions

## Important
This is a front-end prototype only. It does not provide VPN protection or route internet traffic. A real VPN requires a secure VPN gateway/server and a native Android VPN client. Android VPN apps use the platform VPN service APIs; see the [Android VPN developer guide](https://developer.android.com/develop/connectivity/vpn).

## Run locally
Open `index.html` in a browser, or publish the files using a static website host.
